# Muscle-Control-SMASIS
Code used for the paper "Dynamic Control of Muscle Tissue Forces for Biohybrid Robotic Applications" by Grummer et al. from SMASIS 2026. If you have any questions feel free to email me at ryangrummer@gmail.com

### Python Environment Setup
>conda create -n i3_control python

>conda install spyder-kernels

>pip install matplotlib numpy scipy mujoco control cvxpy jupyter alphashape shapely

>conda config --add channels conda-forge

>conda config --set channel_priority strict

>conda install cyipopt pyserial pandas
